# HTTP API 契約

この文書は互換性を維持する方針を定める。ルート・引数・レスポンスの具体的な仕様は、[ルート登録](../../src/index.tsx)、[ハンドラと対応するテスト](../../src/routes/)を参照する。

## 互換性の原則

- 既存のパス・HTTPメソッド、認証要件、入力の意味、レスポンスの型・ステータス・リダイレクト動作を維持する。
- HTML・JSON・CSVの各形式について、既存の呼び出し元が依存する振る舞いを維持する。エラー応答に秘密情報を含めない。
- 変更時は対応するルートテストで互換性を検証する。

## 変更の判断

- **破壊的変更**: 既存の公開面の削除・改名・型や意味の変更、入力の必須化など。実装前に人間レビューを受ける。
- **追加変更**: 既存利用者の動作を維持する新規ルートや任意入力・任意出力の追加。

共通の変更手順は[互換契約のREADME](README.md)に従う。通常のルートや項目の追加は実装・テストで管理し、この文書は互換性の方針が変わる場合に更新する。
